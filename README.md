# نظام مناوبات الحافلات المدرسية

موقع لإدارة مناوبات سائقي الحافلات المدرسية: صفحة عامة لمناوبة اليوم والأسبوع، ولوحة تحكم للمدير والمشرفين.

- الاستضافة: GitHub Pages
- قاعدة البيانات وحسابات الدخول: Supabase
- خطوات الإعداد كاملة في ملف [دليل-الإعداد.md](دليل-الإعداد.md)

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة العامة |
| `admin.html` | لوحة التحكم |
| `config.js` | بيانات الربط مع Supabase (تعدّلها مرة واحدة) |
| `supabase.sql` | الجداول وقواعد الأمان (تشغّله في SQL Editor) |
