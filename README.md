# ScreenFlow — نظام إدارة شاشات الإعلانات عن بُعد

ترفع إعلان (فيديو أو صورة) من جوالك، فيظهر فورًا على شاشة المحل أينما كنت.

| الجزء | الرابط | يُفتح على |
|---|---|---|
| لوحة التحكم | `/admin` | الجوال |
| مشغّل الشاشة | `/tv` | متصفح التلفزيون (Smart TV) |

**المتطلبات:** Node.js الإصدار 18 أو أحدث فقط. لا يحتاج النظام أي مكتبات إضافية ولا `npm install`.

---

## 1) التشغيل على جهازك (للتجربة)

```bash
cd screenflow
node server.js
```

- لوحة التحكم: `http://localhost:3000/admin`
- مشغّل الشاشة: `http://localhost:3000/tv`

**للتجربة على تلفزيون في نفس شبكة الواي فاي:** اعرف عنوان IP لجهازك (مثلًا `192.168.1.20`)، ثم افتح على التلفزيون `http://192.168.1.20:3000/tv` وعلى الجوال `http://192.168.1.20:3000/admin`.

---

## 2) طريقة الاستخدام

1. افتح لوحة التحكم من الجوال، ثم أنشئ حسابًا.
2. افتح `/tv` على متصفح التلفزيون، فيظهر رمز من 6 أرقام.
3. من الجوال اختر **«إضافة شاشة»**، ثم أدخل الرمز وسمِّ الشاشة.
4. من تبويب **«الإعلانات»** اضغط **«رفع إعلان»** واختر فيديو أو صورة من جوالك.
5. تظهر نافذة النشر تلقائيًا. اختر الشاشة واضغط **«نشر الآن»**، فيظهر الإعلان على التلفزيون خلال ثوانٍ.

### المميزات
- **ربط برمز مؤقت:** الربط يتم مرة واحدة، وتتذكر الشاشة حسابك حتى لو أُطفئ التلفزيون.
- **قائمة تشغيل:** عدة إعلانات تُعرض بالترتيب وتتكرر. يمكنك ترتيبها بالأسهم ↑↓.
- **الجدولة (زر ⚙):** تاريخ بداية ونهاية، وساعات يومية مثل عروض الصباح من 9 إلى 12، وأيام محددة من الأسبوع.
- **حالة الشاشة:** متصلة أو غير متصلة، وما الإعلان المعروض عليها الآن.
- **عدة شاشات وفروع** من حساب واحد، مع نشر نفس الإعلان على أكثر من شاشة بضغطة.
- **إعدادات العرض:** ملء الشاشة أو بدون قص، وشاشة عمودية (تدوير 90°)، وتشغيل الصوت أو كتمه.
- **أوامر عن بُعد:** «تعريف الشاشة» يُظهر اسمها عليها، و«إعادة تحميل» يعيد تشغيل المشغّل.
- **العمل دون إنترنت:** تحفظ الشاشة الإعلانات وتستمر بعرضها إذا انقطع الاتصال. يتطلب ذلك HTTPS (انظر القسم 3).
- **إعادة اتصال تلقائية** إذا انقطع الإنترنت أو أُعيد تشغيل السيرفر.

---

## 3) النشر على الإنترنت (لتتحكم من أي مكان)

تحتاج **سيرفر VPS** صغير (مثل DigitalOcean أو Hetzner أو Contabo، بحوالي 5 دولارات شهريًا) و**دومين** (مثل `screens.myshop.com`).

### أ) رفع المشروع وتشغيله
```bash
# على السيرفر (Ubuntu)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
sudo apt install -y nodejs
# انسخ مجلد screenflow إلى /opt/screenflow ثم:
sudo cp /opt/screenflow/deploy/screenflow.service /etc/systemd/system/
sudo systemctl enable --now screenflow
```

### ب) تفعيل HTTPS تلقائيًا عبر Caddy
```bash
sudo apt install -y caddy
# عدّل الدومين في deploy/Caddyfile ثم:
sudo cp /opt/screenflow/deploy/Caddyfile /etc/caddy/Caddyfile
sudo systemctl reload caddy
```
اربط الدومين بعنوان IP للسيرفر (سجل A)، وسيصدر Caddy شهادة SSL مجانية تلقائيًا.

> HTTPS ضروري لميزة **العرض دون إنترنت**، ومهم لحماية كلمة المرور.

### متغيرات الإعداد (اختيارية)
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ السيرفر |
| `ALLOW_REGISTER` | `true` | اجعله `false` بعد إنشاء حسابك لإغلاق التسجيل أمام الآخرين |
| `MAX_UPLOAD_MB` | `500` | أقصى حجم للملف المرفوع |

## 4) نصائح لتلفزيون المحل
- اجعل `https://دومينك/tv` **الصفحة الرئيسية** لمتصفح التلفزيون، أو أضفه للمفضلة.
- اضغط أي زر في الريموت مرة واحدة لتفعيل **ملء الشاشة** والصوت.
- عطّل من إعدادات التلفزيون: **وضع توفير الطاقة** و**الإيقاف التلقائي** و**شاشة التوقف**.
- استخدم فيديو **MP4 (H.264)** بدقة 1080p، فهو المدعوم على كل التلفزيونات تقريبًا.
- زر **R** أو **الزر الأحمر** في الريموت يعيد تحميل المشغّل.
- إذا كان متصفح التلفزيون ضعيفًا، فجهاز **Android TV Box** رخيص مع Chrome يعطي أفضل أداء.

## 5) هيكل المشروع
```
screenflow/
├── server.js            ← السيرفر: الحسابات، الشاشات، الرفع، النشر
├── db.js                ← قاعدة البيانات (ملف data/db.json)
├── lib/websocket.js     ← الاتصال الفوري مع الشاشات
├── public/admin/        ← لوحة التحكم (الجوال)
├── public/tv/           ← مشغّل التلفزيون + الحفظ دون إنترنت (sw.js)
├── deploy/              ← ملفات النشر (systemd + Caddy)
├── data/                ← تُنشأ تلقائيًا: البيانات
└── uploads/             ← تُنشأ تلقائيًا: الفيديوهات والصور
```

**النسخ الاحتياطي:** يكفي حفظ نسخة من مجلدَي `data/` و`uploads/`.

**للتوسع لاحقًا** (مئات الشاشات): يمكن استبدال `db.js` بـ MySQL، ونقل `uploads` إلى Cloudflare R2، دون تغيير لوحة التحكم أو المشغّل.
